# 0124. Binary Tree Maximum Path Sum

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/binary-tree-maximum-path-sum/

## Approach

Postorder DFS returns the best downward gain while updating the best path through each node.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h)`
