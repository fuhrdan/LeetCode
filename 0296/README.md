# 0296. Best Meeting Point

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/best-meeting-point/

## Approach

Collect row and column coordinates of all homes; the median row and median column minimize Manhattan distance.

## Complexity

- **Time:** `O(mn)`
- **Space:** `O(homes)`
