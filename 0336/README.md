# 0336. Palindrome Pairs

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/palindrome-pairs/

## Approach

For every split of every word, if one side is a palindrome, look up the reverse of the other side.

## Complexity

- **Time:** `O(n · L²) average`
- **Space:** `O(nL)`
