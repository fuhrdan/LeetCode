# 0368. Largest Divisible Subset

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/largest-divisible-subset/

## Approach

Sort the numbers, then DP the longest divisible chain ending at each index while storing predecessors for reconstruction.

## Complexity

- **Time:** `O(n²)`
- **Space:** `O(n)`
