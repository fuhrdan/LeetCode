# 0025. Reverse Nodes in k-Group

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/reverse-nodes-in-k-group/

## Approach

Find groups of k nodes and reverse each complete group in place.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
