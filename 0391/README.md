# 0391. Perfect Rectangle

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/perfect-rectangle/

## Approach

The total small-rectangle area must equal the bounding rectangle area, and corner toggling must leave exactly the four outer corners.

## Complexity

- **Time:** `O(n) average`
- **Space:** `O(n)`
