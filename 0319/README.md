# 0319. Bulb Switcher

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/bulb-switcher/

## Approach

Only perfect squares have an odd number of divisors, so exactly floor(sqrt(n)) bulbs remain on.
