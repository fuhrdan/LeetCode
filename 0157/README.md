# 0157. Read N Characters Given Read4

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/read-n-characters-given-read4/

## Approach

Repeatedly call read4 into a temporary buffer and copy at most n characters.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
