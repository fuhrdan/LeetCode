# 0375. Guess Number Higher or Lower II

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/guess-number-higher-or-lower-ii/

## Approach

Interval DP tries each possible first guess and pays that guess plus the worse of the two remaining intervals.

## Complexity

- **Time:** `O(n^3)`
- **Space:** `O(n^2)`
