# 0304. Range Sum Query 2D - Immutable

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/range-sum-query-2d-immutable/

## Approach

Build a 2D prefix-sum matrix and answer each rectangle by inclusion-exclusion.

## Complexity

- **Time:** `O(mn) build, O(1) query`
- **Space:** `O(mn)`
