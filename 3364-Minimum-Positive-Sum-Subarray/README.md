# 3364. Minimum Positive Sum Subarray

**Difficulty:** Easy

We need the smallest positive sum among all contiguous subarrays whose length is between `l` and `r`, inclusive.

For each allowed window length, use a sliding sum.

## Complexity

- Time: `O(n * (r - l + 1))`
- Space: `O(1)`
