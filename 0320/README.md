# 0320. Generalized Abbreviation

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/generalized-abbreviation/

## Approach

Backtrack by either abbreviating the current character or emitting pending count plus the character.

## Complexity

- **Time:** `O(2^n * n)`
- **Space:** `O(n)`
