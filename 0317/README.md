# 0317. Shortest Distance from All Buildings

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/shortest-distance-from-all-buildings/

## Approach

Run BFS from every building, accumulating distances and reach counts for empty cells; choose a cell reached by all buildings.

## Complexity

- **Time:** `O(Bmn)`
- **Space:** `O(mn)`
