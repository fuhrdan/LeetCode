# 0349. Intersection of Two Arrays

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/intersection-of-two-arrays/

## Approach

Insert the first array into a set and add each matching value from the second array to a result set.

## Complexity

- **Time:** `O(n+m) average`
- **Space:** `O(n+m)`
