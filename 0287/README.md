# 0287. Find the Duplicate Number

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/find-the-duplicate-number/

## Approach

Treat values as next pointers and use Floyd cycle detection; the cycle entrance is the duplicate.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
