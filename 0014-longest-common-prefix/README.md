# 0014. Longest Common Prefix

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/longest-common-prefix/

## Approach

Shrink a candidate prefix until every string matches it.

## Complexity

- **Time:** `O(total characters)`
- **Space:** `O(1) auxiliary`
