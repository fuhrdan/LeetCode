# 0371. Sum of Two Integers

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/sum-of-two-integers/

## Approach

Use XOR for sum bits and AND-shift for carry bits until no carry remains.

## Complexity

- **Time:** `O(number of bits)`
- **Space:** `O(1)`
