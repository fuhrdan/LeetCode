# 0382. Linked List Random Node

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/linked-list-random-node/

## Approach

Use reservoir sampling so each node is chosen with equal probability during one traversal.

## Complexity

- **Time:** `O(n) per getRandom`
- **Space:** `O(1)`
