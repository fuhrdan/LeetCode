# 0267. Palindrome Permutation II

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/palindrome-permutation-ii/

## Approach

Build half of the palindrome from character pairs, permute that half uniquely, and mirror it around an optional center.

## Complexity

- **Time:** `O(n * permutations)`
- **Space:** `O(n)`
