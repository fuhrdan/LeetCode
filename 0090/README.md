# 0090. Subsets II

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/subsets-ii/

## Approach

Sort then backtrack, skipping equal values at the same recursion depth.

## Complexity

- **Time:** `O(n * 2^n)`
- **Space:** `O(n) recursion plus output`
