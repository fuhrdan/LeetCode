# 0086. Partition List

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/partition-list/

## Approach

Build two linked lists for nodes below x and nodes at least x, then join them.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
