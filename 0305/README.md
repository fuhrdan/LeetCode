# 0305. Number of Islands II

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/number-of-islands-ii/

## Approach

Use union-find as land is added; each successful union reduces the island count by one.

## Complexity

- **Time:** `O(k α(mn))`
- **Space:** `O(mn)`
