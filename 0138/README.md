# 0138. Copy List with Random Pointer

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/copy-list-with-random-pointer/

## Approach

Interleave cloned nodes with originals, wire random pointers, then detach the copied list.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1) auxiliary`
