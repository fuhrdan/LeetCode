# 0266. Palindrome Permutation

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/palindrome-permutation/

## Approach

A string can permute to a palindrome iff at most one character has an odd count.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
