# 0017. Letter Combinations of a Phone Number

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/letter-combinations-of-a-phone-number/

## Approach

Backtracking over the letters mapped from each digit.

## Complexity

- **Time:** `O(4^n)`
- **Space:** `O(n) recursion plus output`
