# 0293. Flip Game

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/flip-game/

## Approach

For every occurrence of '++', create a copy with that pair changed to '--'.

## Complexity

- **Time:** `O(n^2) output copying`
- **Space:** `O(n) per result`
