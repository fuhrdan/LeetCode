# 0143. Reorder List

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/reorder-list/

## Approach

Find the midpoint, reverse the second half, then weave the two halves together.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
