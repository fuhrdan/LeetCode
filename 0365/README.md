# 0365. Water and Jug Problem

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/water-and-jug-problem/

## Approach

By Bézout's identity, z liters is measurable iff z does not exceed total capacity and is divisible by gcd(x,y).

## Complexity

- **Time:** `O(log min(x,y))`
- **Space:** `O(1)`
