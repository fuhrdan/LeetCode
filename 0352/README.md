# 0352. Data Stream as Disjoint Intervals

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/data-stream-as-disjoint-intervals/

## Approach

Maintain sorted disjoint intervals and merge a newly inserted value with adjacent or overlapping intervals.
