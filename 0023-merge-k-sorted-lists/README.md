# 0023. Merge k Sorted Lists

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/merge-k-sorted-lists/

## Approach

Repeatedly merge list pairs in a divide-and-conquer fashion.

## Complexity
