# 0397. Integer Replacement

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/integer-replacement/

## Approach

For odd n, choose +1 or -1 based on which produces more trailing zero bits, with 3 handled specially.

## Complexity

- **Time:** `O(log n)`
- **Space:** `O(1)`
