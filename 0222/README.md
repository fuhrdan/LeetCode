# 0222. Count Complete Tree Nodes

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/count-complete-tree-nodes/

## Approach

Compare leftmost and rightmost heights; equal heights mean the subtree is perfect.

## Complexity

- **Time:** `O(log^2 n)`
- **Space:** `O(log n)`
