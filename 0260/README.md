# 0260. Single Number III

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/single-number-iii/

## Approach

XOR all values, isolate one differing bit, then partition numbers by that bit.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
