# 0341. Flatten Nested List Iterator

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/flatten-nested-list-iterator/

## Approach

Maintain a stack of nested items; expand list nodes lazily until an integer is on top.

## Complexity

- **Time:** `O(total elements) amortized`
- **Space:** `O(depth)`
