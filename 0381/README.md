# 0381. Insert Delete GetRandom O(1) - Duplicates allowed

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/insert-delete-getrandom-o1-duplicates-allowed/

## Approach

Store all values in an array and map each value to a set of its array indices; removal swaps one occurrence with the last element.

## Complexity

- **Time:** `O(1) average per operation`
- **Space:** `O(n)`
