# 0007. Reverse Integer

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/reverse-integer/

## Approach

Pop digits and check 32-bit overflow before pushing each digit.

## Complexity

- **Time:** `O(log |x|)`
