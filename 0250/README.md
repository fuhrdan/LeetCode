# 0250. Count Univalue Subtrees

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/count-univalue-subtrees/

## Approach

Postorder recursion checks whether both child subtrees match the current node and counts valid subtrees.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h)`
