# 0112. Path Sum

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/path-sum/

## Approach

Subtract node values while descending and test the remaining sum at leaves.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h)`
