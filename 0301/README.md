# 0301. Remove Invalid Parentheses

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/remove-invalid-parentheses/

## Approach

Use BFS by deletion depth; the first level containing valid strings gives all minimum-removal answers.

## Complexity

- **Time:** `O(2^n * n) worst case`
- **Space:** `O(2^n)`
