# 0225. Implement Stack using Queues

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/implement-stack-using-queues/

## Approach

Use one queue; after push, rotate earlier elements behind the new element.

## Complexity

- **Time:** `O(n) push, O(1) pop/top`
- **Space:** `O(n)`
