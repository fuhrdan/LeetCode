# 0311. Sparse Matrix Multiplication

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/sparse-matrix-multiplication/

## Approach

Skip zero entries in the left matrix and only propagate nonzero products.

## Complexity

- **Time:** `O(nonzero-aware multiplication)`
- **Space:** `O(mn) output`
