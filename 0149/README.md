# 0149. Max Points on a Line

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/max-points-on-a-line/

## Approach

For each anchor, normalize slopes with gcd and count equal directions.

## Complexity

- **Time:** `O(n^2)`
- **Space:** `O(n)`
