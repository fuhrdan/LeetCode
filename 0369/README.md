# 0369. Plus One Linked List

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/plus-one-linked-list/

## Approach

Use a dummy node and remember the rightmost node whose value is not 9; increment it and zero every node after it.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
