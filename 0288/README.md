# 0288. Unique Word Abbreviation

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/unique-word-abbreviation/

## Approach

Map each abbreviation to the unique dictionary word that owns it, or mark it ambiguous.

## Complexity

- **Time:** `O(total dictionary chars), O(1) query average`
- **Space:** `O(n)`
