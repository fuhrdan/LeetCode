# 0214. Shortest Palindrome

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/shortest-palindrome/

## Approach

Use KMP on s + separator + reverse(s) to find the longest palindromic prefix.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(n)`
