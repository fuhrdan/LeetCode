# 0151. Reverse Words in a String

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/reverse-words-in-a-string/

## Approach

Split into words, discard extra spaces, and rebuild in reverse order.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(n)`
