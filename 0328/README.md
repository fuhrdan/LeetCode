# 0328. Odd Even Linked List

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/odd-even-linked-list/

## Approach

Relink nodes in-place into odd-index and even-index chains, then append the even chain after the odd chain.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
