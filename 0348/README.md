# 0348. Design Tic-Tac-Toe

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/design-tic-tac-toe/

## Approach

Track signed counts for each row, column, and the two diagonals; reaching ±n means that player wins.

## Complexity

- **Time:** `O(1) per move`
- **Space:** `O(n)`
