# 0114. Flatten Binary Tree to Linked List

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/flatten-binary-tree-to-linked-list/

## Approach

Reverse-preorder recursion rewires each node's right pointer to the previously processed node.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h)`
