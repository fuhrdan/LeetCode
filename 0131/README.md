# 0131. Palindrome Partitioning

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/palindrome-partitioning/

## Approach

Backtrack over every palindromic prefix of the remaining suffix.

## Complexity

- **Time:** `O(n*2^n) worst case`
- **Space:** `O(n) recursion plus output`
