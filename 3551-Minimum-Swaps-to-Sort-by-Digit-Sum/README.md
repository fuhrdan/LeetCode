# 3551. Minimum Swaps to Sort by Digit Sum

Sort by `(digit sum, value)` and count permutation cycles.

Because all values are distinct, the target ordering is unique. After sorting, map each original index to its target index. A cycle of length `L` needs exactly `L - 1` swaps.

## Complexity
- Time: `O(n log n)`
- Space: `O(n)`
