# 0360. Sort Transformed Array

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/sort-transformed-array/

## Approach

Because a quadratic is monotonic away from its vertex, use two pointers on the sorted input and fill the output from the correct end based on the sign of a.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(n)`
