# 0226. Invert Binary Tree

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/invert-binary-tree/

## Approach

Recursively swap the left and right subtrees at every node.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h)`
