# 0280. Wiggle Sort

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/wiggle-sort/

## Approach

Single pass swaps adjacent values whenever the current inequality does not match the required wiggle pattern.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
