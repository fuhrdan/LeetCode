# 0357. Count Numbers with Unique Digits

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/count-numbers-with-unique-digits/

## Approach

Count valid numbers by length: 9 choices for the first digit, then decreasing unused-digit choices.

## Complexity

- **Time:** `O(min(n,10))`
- **Space:** `O(1)`
