# 0316. Remove Duplicate Letters

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/remove-duplicate-letters/

## Approach

Use a monotonic stack; pop larger letters when they appear again later, while keeping each letter once.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
