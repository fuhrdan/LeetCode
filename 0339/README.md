# 0339. Nested List Weight Sum

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/nested-list-weight-sum/

## Approach

DFS through the nested list while carrying the current depth and adding integer × depth.

## Complexity

- **Time:** `O(total nested elements)`
- **Space:** `O(depth)`
