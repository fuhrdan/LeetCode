# 0326. Power of Three

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/power-of-three/

## Approach

Repeatedly divide by 3 while divisible; the number is a power of three iff the result becomes 1.

## Complexity

- **Time:** `O(log₃ n)`
- **Space:** `O(1)`
