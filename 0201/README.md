# 0201. Bitwise AND of Numbers Range

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/bitwise-and-of-numbers-range/

## Approach

Right-shift both bounds until they share the same prefix, then shift that prefix back.

## Complexity

- **Time:** `O(log n)`
- **Space:** `O(1)`
