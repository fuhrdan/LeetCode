# 0240. Search a 2D Matrix II

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/search-a-2d-matrix-ii/

## Approach

Start at the top-right corner and move left for values too large or down for values too small.

## Complexity

- **Time:** `O(m+n)`
- **Space:** `O(1)`
