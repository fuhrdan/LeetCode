# 0385. Mini Parser

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/mini-parser/

## Approach

Parse recursively: an integer becomes a scalar NestedInteger; '[' starts a list whose comma-separated children are parsed until ']'.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(depth)`
