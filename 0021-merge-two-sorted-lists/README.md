# 0021. Merge Two Sorted Lists

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/merge-two-sorted-lists/

## Approach

Merge using a dummy head and advance the smaller list node.

## Complexity

- **Time:** `O(m+n)`
- **Space:** `O(1) auxiliary`
