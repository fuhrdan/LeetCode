# 0333. Largest BST Subtree

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/largest-bst-subtree/

## Approach

Postorder returns whether a subtree is a BST plus its size and min/max values; invalid subtrees propagate failure.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h)`
