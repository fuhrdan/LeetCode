# 0009. Palindrome Number

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/palindrome-number/

## Approach

Reverse only half of the integer and compare the halves.

## Complexity

- **Time:** `O(log x)`
- **Space:** `O(1)`
