# 0324. Wiggle Sort II

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/wiggle-sort-ii/

## Approach

Sort a copy, then interleave the reversed lower half into even positions and reversed upper half into odd positions.

## Complexity

- **Time:** `O(n log n)`
- **Space:** `O(n)`
