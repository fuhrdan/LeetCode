# 0130. Surrounded Regions

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/surrounded-regions/

## Approach

Flood-fill border-connected O cells, then flip the remaining enclosed cells.

## Complexity

- **Time:** `O(mn)`
- **Space:** `O(mn) worst-case recursion/queue`
