# 0399. Evaluate Division

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/evaluate-division/

## Approach

Build a weighted bidirectional graph of variable ratios and answer each query with DFS multiplying edge weights.

## Complexity

- **Time:** `O(Q·(V+E))`
- **Space:** `O(V+E)`
