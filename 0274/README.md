# 0274. H-Index

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/h-index/

## Approach

Sort citations and find the first position whose citation count supports the number of remaining papers.

## Complexity

- **Time:** `O(n log n)`
- **Space:** `O(1) auxiliary`
