# 0303. Range Sum Query - Immutable

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/range-sum-query-immutable/

## Approach

Precompute prefix sums so each range sum is a difference of two prefix values.

## Complexity

- **Time:** `O(n) build, O(1) query`
- **Space:** `O(n)`
