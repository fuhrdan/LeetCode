# 0233. Number of Digit One

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/number-of-digit-one/

## Approach

Count ones independently at each decimal place using high/current/low digit decomposition.

## Complexity

- **Time:** `O(log n)`
- **Space:** `O(1)`
