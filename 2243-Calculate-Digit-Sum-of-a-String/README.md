# 2243. Calculate Digit Sum of a String

**Difficulty:** Easy

Repeatedly split the string into consecutive groups of size `k`.

For each group:
1. Sum its digits.
2. Convert the sum to decimal text.
3. Append it to the next string.

Stop when `s.length <= k`.

## Complexity

- Time: `O(total characters processed)`
- Space: `O(n)`
