# 0398. Random Pick Index

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/random-pick-index/

## Approach

Use reservoir sampling across matching indices so each occurrence of target is selected uniformly.

## Complexity

- **Time:** `O(n) per pick`
- **Space:** `O(1)`
