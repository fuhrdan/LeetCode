# 0079. Word Search

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/word-search/

## Approach

DFS backtracking from each cell while marking visited cells in-place.

## Complexity

- **Time:** `O(mn * 4^L) worst case`
- **Space:** `O(L) recursion`
