# 0318. Maximum Product of Word Lengths

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/maximum-product-of-word-lengths/

## Approach

Represent each word's letters as a bitmask and compare pairs whose masks do not overlap.

## Complexity

- **Time:** `O(n^2 + total chars)`
- **Space:** `O(n)`
