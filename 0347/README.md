# 0347. Top K Frequent Elements

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/top-k-frequent-elements/

## Approach

Count frequencies, then bucket values by frequency and collect from highest frequency downward.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(n)`
