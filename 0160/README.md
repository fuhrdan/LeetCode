# 0160. Intersection of Two Linked Lists

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/intersection-of-two-linked-lists/

## Approach

Switch each pointer to the other list head when it reaches the end.

## Complexity

- **Time:** `O(m+n)`
- **Space:** `O(1)`
