# 0390. Elimination Game

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/elimination-game/

## Approach

Track the first surviving number, step size, direction, and remaining count while eliminating every other number.

## Complexity

- **Time:** `O(log n)`
- **Space:** `O(1)`
