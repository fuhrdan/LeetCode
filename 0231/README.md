# 0231. Power of Two

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/power-of-two/

## Approach

A positive power of two has exactly one set bit, so n & (n - 1) is zero.

## Complexity

- **Time:** `O(1)`
- **Space:** `O(1)`
