# 0315. Count of Smaller Numbers After Self

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/count-of-smaller-numbers-after-self/

## Approach

Coordinate-compress values and scan from right to left with a Fenwick tree counting smaller ranks.

## Complexity

- **Time:** `O(n log n)`
- **Space:** `O(n)`
