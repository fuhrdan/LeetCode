# 0285. Inorder Successor in BST

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/inorder-successor-in-bst/

## Approach

Walk from the root; whenever p is smaller than the current node, record that node as a successor candidate.

## Complexity

- **Time:** `O(h)`
- **Space:** `O(1)`
