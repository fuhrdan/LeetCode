# 0359. Logger Rate Limiter

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/logger-rate-limiter/

## Approach

Store the last printed timestamp for each message and allow it again only after 10 seconds.

## Complexity

- **Time:** `O(1) average`
- **Space:** `O(messages)`
