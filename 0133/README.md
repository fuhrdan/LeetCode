# 0133. Clone Graph

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/clone-graph/

## Approach

DFS/BFS clones each node once while memoizing original-to-copy mappings.

## Complexity

- **Time:** `O(V+E)`
- **Space:** `O(V)`
