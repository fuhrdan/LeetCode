# 0236. Lowest Common Ancestor of a Binary Tree

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/

## Approach

Postorder recursion returns a target when found and the current node when targets appear in both subtrees.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h)`
