# 0300. Longest Increasing Subsequence

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/longest-increasing-subsequence/

## Approach

Patience sorting maintains the smallest possible tail for an increasing subsequence of every length.

## Complexity

- **Time:** `O(n log n)`
- **Space:** `O(n)`
