# 0313. Super Ugly Number

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/super-ugly-number/

## Approach

Dynamic programming keeps one pointer per prime and advances every pointer that produces the current minimum.

## Complexity

- **Time:** `O(nk)`
- **Space:** `O(n+k)`
