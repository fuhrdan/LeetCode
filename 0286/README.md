# 0286. Walls and Gates

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/walls-and-gates/

## Approach

Multi-source BFS starts from all gates and fills each empty room with its shortest distance.

## Complexity

- **Time:** `O(mn)`
- **Space:** `O(mn)`
