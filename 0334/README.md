# 0334. Increasing Triplet Subsequence

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/increasing-triplet-subsequence/

## Approach

Keep the smallest first and second values seen; any value larger than both proves an increasing triplet.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
