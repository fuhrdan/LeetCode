# 0380. Insert Delete GetRandom O(1)

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/insert-delete-getrandom-o1/

## Approach

Store values in an array and map each value to its index; deletion swaps the target with the array's last element.

## Complexity

- **Time:** `O(1) average per operation`
- **Space:** `O(n)`
