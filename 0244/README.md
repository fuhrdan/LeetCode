# 0244. Shortest Word Distance II

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/shortest-word-distance-ii/

## Approach

Pre-index each word's positions, then merge two sorted position lists with two pointers.

## Complexity

- **Time:** `O(n) build, O(a+b) query`
- **Space:** `O(n)`
