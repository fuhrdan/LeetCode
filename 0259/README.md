# 0259. 3Sum Smaller

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/3sum-smaller/

## Approach

Sort, then use two pointers; when a sum is small enough, every index between left and right works.

## Complexity

- **Time:** `O(n^2)`
- **Space:** `O(1) auxiliary`
