# 0366. Find Leaves of Binary Tree

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/find-leaves-of-binary-tree/

## Approach

Postorder returns each node's height from the leaves; nodes with the same height belong to the same removal round.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(h) recursion plus output`
