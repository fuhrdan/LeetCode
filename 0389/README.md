# 0389. Find the Difference

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/find-the-difference/

## Approach

XOR all characters from both strings; matching characters cancel and leave the extra one.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
