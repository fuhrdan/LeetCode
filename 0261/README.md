# 0261. Graph Valid Tree

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/graph-valid-tree/

## Approach

A graph is a tree iff it has exactly n-1 edges and all nodes are connected.

## Complexity

- **Time:** `O(n+e)`
- **Space:** `O(n+e)`
