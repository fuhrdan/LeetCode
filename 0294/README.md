# 0294. Flip Game II

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/flip-game-ii/

## Approach

Backtrack over every legal flip; the current player wins if any move leaves the opponent unable to win.

## Complexity

- **Time:** `Exponential, memoizable`
- **Space:** `O(n) recursion`
