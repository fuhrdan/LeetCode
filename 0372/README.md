# 0372. Super Pow

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/super-pow/

## Approach

Process exponent digits left to right using (a^prefix)^10 × a^digit modulo 1337.

## Complexity

- **Time:** `O(len(b) · log 10)`
- **Space:** `O(1)`
