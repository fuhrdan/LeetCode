# 0394. Decode String

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/decode-string/

## Approach

Use stacks for repeat counts and prior strings; '[' starts a nested segment and ']' expands it.

## Complexity

- **Time:** `O(output length)`
- **Space:** `O(depth + output)`
