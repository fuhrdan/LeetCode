# 0387. First Unique Character in a String

**Difficulty:** Easy  
**LeetCode:** https://leetcode.com/problems/first-unique-character-in-a-string/

## Approach

Count each letter, then scan again for the first character whose count is one.

## Complexity

- **Time:** `O(n)`
- **Space:** `O(1)`
