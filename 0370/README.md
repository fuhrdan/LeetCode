# 0370. Range Addition

**Difficulty:** Medium  
**LeetCode:** https://leetcode.com/problems/range-addition/

## Approach

Use a difference array: add at each range start, subtract after each range end, then prefix-sum once.

## Complexity

- **Time:** `O(length + updates)`
- **Space:** `O(length)`
