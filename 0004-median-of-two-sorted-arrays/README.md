# 0004. Median of Two Sorted Arrays

**Difficulty:** Hard  
**LeetCode:** https://leetcode.com/problems/median-of-two-sorted-arrays/

## Approach

Binary-search the partition of the smaller sorted array.

## Complexity

- **Time:** `O(log(min(m,n)))`
- **Space:** `O(1)`
